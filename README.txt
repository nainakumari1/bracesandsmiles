BRACES & SMILES WEBSITE (Node.js, zero dependencies)

HOSTINGER UPLOAD
1. hPanel > Websites > Add Website > Node.js Apps > upload this ZIP.
2. Startup file: server.js | Node 18+ | Start command: npm start
3. Deploy, then connect your domain.

BEFORE LAUNCH
- In pages.js set SITE.url to your real domain (used for SEO and sitemap).
- Put your photos in public/images (.webp/.jpg) and gallery photos in public/images/gallery, then list them in public/js/main.js (photos array).
- Phone, hours, ratings and services are at the top of pages.js.
- Add Dr. Nisheeth's verified qualifications in pages.js (About page).
Run locally: npm start -> http://localhost:3000
